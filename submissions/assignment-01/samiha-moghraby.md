## Project Description

TechTalks is a developer community platform built for Assignment 1 of the TechTalks Full-Stack Bootcamp.

The project uses Next.js 16 with the App Router, TypeScript, and Tailwind CSS. It includes dynamic community routes, developer profiles, nested developer posts, reusable components, local static data, loading states, 404 handling, and responsive accessible UI.

The project uses Server Components for static data rendering and Client Components where real interactivity is required.
