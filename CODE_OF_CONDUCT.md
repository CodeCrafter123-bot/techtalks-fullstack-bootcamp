# Code of Conduct

## Our Standards

All participants in the TechTalks Full-Stack Bootcamp are expected to maintain a respectful and professional environment. The following standards apply to all interactions within this repository.

### Required Behavior

- Communicate respectfully and professionally at all times.
- Provide constructive feedback during code reviews and discussions.
- Support fellow students by asking and answering questions clearly.
- Take responsibility for your own work and submissions.
- Accept mentor feedback with openness and a willingness to improve.

### Prohibited Behavior

- Harassment, insults, or disrespectful comments directed at any person.
- Plagiarism or submitting work that is not your own without proper attribution.
- Editing, deleting, or modifying another student's submission files.
- Spamming the repository with unrelated content, issues, or pull requests.
- Sharing passwords, API keys, access tokens, environment variables, or any private information in issues, pull requests, or comments.
- Unprofessional behavior during code reviews or technical discussions.

## Enforcement

TechTalks may remove content, close issues or pull requests, and restrict participation for any participant who violates these standards.

If you witness a violation or experience any misconduct, please report it through the appropriate channel provided by TechTalks.
